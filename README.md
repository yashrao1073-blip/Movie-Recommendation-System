# 🎬 Movie Recommendation System

A content-based Movie Recommendation System built using **Python, Scikit-learn, and Streamlit**. It recommends similar movies using **CountVectorizer**, **Cosine Similarity**, and the **TMDb API** to display movie posters.

## 🚀 Features
- Content-based movie recommendations
- TMDb API integration for posters
- Interactive Streamlit interface

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- TMDb API

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
